# SlipFit AI

**AI that slips into the systems we already trust.**

We already run our work on systems: GTD, PARA, Kanban, a Notion board. They pay off, but keeping them up takes time: capturing, filing, reviewing, updating. SlipFit AI fits AI into those methods to take on the upkeep, so less time goes to maintaining the system and more goes to getting value out of it. The repos here hold the files that go with each video.
